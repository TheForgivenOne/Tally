10 · Gesture contract

Only these six. Every gesture has a visible twin; hidden-only is banned.

A11y: gestures are shortcuts — tap does the same; timed UI has a tap alternative.

1 · Tap — everything primary: shutter 68px, Add, steppers, tabs
2 · Swipe-down grabber — dismiss dock (✕ does the same)
3 · Swipe-left row — Remove + 5s Undo toast, destructive only
4 · Pull-to-refresh — store list + price history only
5 · Edge-swipe back — system only, no in-app horizontal nav
6 · Map set — drag / pinch / double-tap / rotate, Shop tab only
